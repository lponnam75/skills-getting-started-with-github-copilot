## How to Run the Workspace

This repository contains a FastAPI web application for Mergington High School's extracurricular activities. Here's how to get it running:

### Prerequisites
```bash
pip install fastapi uvicorn
```

### Quick Start
Choose one of these methods to run the application:

**Method 1: Direct Python execution**
```bash
cd src
python app.py
```

**Method 2: Using uvicorn**
```bash
uvicorn src.app:app --reload
```

**Method 3: VS Code with Codespaces (Recommended for the exercise)**
1. Open in GitHub Codespaces or VS Code
2. Press F5 or use "Run and Debug" → "Launch Mergington WebApp"

### Access the Application
- **Web Interface**: http://localhost:8000
- **API Documentation**: http://localhost:8000/docs
- **Alternative Documentation**: http://localhost:8000/redoc

For more details about the application features, see the [src/README.md](src/README.md) file.
